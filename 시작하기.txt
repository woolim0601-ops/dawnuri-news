새벽누리 GitHub 업로드용 패키지 — 처음 시작하기

이 압축파일 안에는 GitHub 저장소의 맨 위에 올려야 하는 파일들이 들어 있습니다.

1. 압축을 풀어 주세요.
2. GitHub에서 새 비공개(Private) 저장소 `dawnuri-news`를 만듭니다.
3. 저장소의 Add file → Upload files로 이동합니다.
4. 압축을 푼 폴더 자체가 아니라, 폴더 안의 모든 내용(파일 및 하위 폴더)을 업로드하세요.
   특히 `.pages.yml`, `build.mjs`, `package.json`, `content`, `public`이 저장소 맨 위에 있어야 합니다.
   macOS에서 점으로 시작하는 파일이 안 보이면 Finder에서 Command + Shift + . 키로 숨김 파일을 보이게 합니다.
5. Commit changes를 누릅니다.
6. 성인 보호자와 함께 Cloudflare Pages에 연결합니다. 프레임워크=None, 빌드 명령어=`npm run build`, 결과 폴더=`dist`, 루트=저장소 최상위로 설정합니다.
7. app.pagescms.org에서 GitHub를 연결하고 이 저장소를 선택합니다.

공개 전에 시연용 기사와 사진을 실제 검증된 자료로 교체하세요. 처음에는 별도 도메인을 구입할 필요 없습니다.
상세 설명은 README.md에 있습니다.
