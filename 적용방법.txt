새벽누리 v12 · 기사 분야 추가 및 소개 레이아웃 수정

적용 파일 4개 (기존 파일의 같은 위치에 교체)
- build.mjs : 기사 분야 목록/메뉴/분류 페이지/검색 안내/소개 페이지 구조
- .pages.yml : Pages CMS 기사 분야 선택 항목 추가 (숨김 파일)
- public/assets/main.js : 검색 화면에서 새 분야 표시
- public/assets/style.css : 상단 메뉴 반응형 및 WHO WE ARE 여백 개선

신규 기사 분야: 스포츠, 교육, 경제, 과학·기술, 환경, 정치, 국제, 오피니언
기존 기사 파일과 사이트 기본 설정은 수정하지 않았습니다.

주의: GitHub가 Public이면 draft 상태의 원고도 파일 내용은 공개될 수 있습니다.
배포는 기존 GitHub Actions 설정을 이용합니다. 기존 deploy.yml은 변경하지 마세요.
현재 공개된 실제 저장소에 직접 수정하지 않은 상태이므로, GitHub에 파일을 업로드해야 반영됩니다.
