새벽누리 v11 - 소개 페이지 문의 제목 한 줄 수정

수정 사항:
- 소개 페이지 CONTACT의 '새로운 이야기를 기다립니다.'를 한 줄로 표시
- 모바일에서 제목 크기를 화면에 맞게 조절하여 글자가 잘리지 않도록 구성
- 다른 기사·이메일·이미지 내용은 그대로 유지

GitHub dawnuri-news 저장소 루트에서 Add file → Upload files.
이 압축파일을 풀고 그 안의 build.mjs와 public 폴더를 끌어놓으세요.
기존에 같은 경로가 있다면 변경 사항으로 올라가야 합니다.
Commit changes 를 누르고 Actions → Deploy Dawnuri News가 초록색으로 끝나면 새로고침하세요.
참고: 기존 파일 교체는 GitHub의 웹 업로드 인터페이스에서 기존 이름 충돌 알림이 뜰 수 있습니다.
그 경우 파일을 각각 열어서 편집(연필 아이콘)으로 내용을 교체하세요.

주의: ZIP 전체/상위 폴더를 올리지 말고 안의 build.mjs 및 public을 올리세요.
