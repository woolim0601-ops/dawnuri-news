GitHub 적용 방법
1. dawnuri-news 저장소에서 build.mjs 파일을 본 수정본으로 교체하세요.
2. 원형 로고 관련 불필요한 CSS도 제거하려면 public/assets/style.css 역시 교체하세요.
3. Commit changes를 누르세요.
4. Cloudflare 연결 시 해당 수정이 배포됩니다.
