개인정보처리방침

새벽누리는 이용자의 개인정보를 소중하게 다루며, 처리 목적과 보유 기간을 알기 쉽게 안내합니다.

게시 전 확인이 필요한 초안입니다. Cloudflare D1의 실제 데이터 저장 지역, 각 서비스의 로그 보유 기간, 문의 이메일을 처리하는 업체를 확인한 뒤 아래 ‘검토 메모’를 반영해 공개해 주세요.

1. 개인정보 처리 목적

새벽누리는 다음 목적에 필요한 범위에서 개인정보를 처리합니다.

  • 기자실 계정 발급·로그인 확인, 권한 관리, 계정 보안
  • 기사 원고의 작성·검토·수정·발행 및 사진 관리
  • 기자 소개와 공개 프로필 운영
  • 이용자 문의에 답변하고 서비스 오류·부정 이용을 확인

새벽누리 기자실은 공개 회원가입을 제공하지 않으며, 편집장이 계정을 발급합니다.

2. 처리하는 개인정보 항목과 보유 기간

구분처리 항목목적보유 기간
기자실 계정로그인 아이디, 비밀번호 해시값, 계정 상태·역할계정 인증과 권한 관리계정 삭제 또는 이용 종료 시까지. 비밀번호 원문은 저장하지 않습니다.
로그인 세션인증 쿠키값, 서버에 저장된 쿠키 해시값, 만료 시각로그인 상태 유지와 계정 보호로그인 세션은 발급 후 8시간 동안 유효하며, 로그아웃·계정 변경 등 필요한 경우 삭제합니다.
기자 프로필공개 기자 ID, 공개 이름, 소개글, 프로필 사진기자 소개와 기사 작성자 표시공개 동의가 유지되는 동안. 공개 중단·삭제 요청을 받으면 확인 후 처리합니다.
기사 원고·사진제목, 분야, 요약, 본문, 작성자 표시, 사진과 사진 설명·출처원고 관리, 편집·검토, 기사 발행비공개 원고는 삭제할 때까지. 발행 콘텐츠는 비공개·삭제 처리 전까지 보관·공개될 수 있습니다.
문의이용자가 이메일에 직접 적어 보낸 회신 주소, 이름, 문의 내용문의 확인과 답변문의 처리 완료 후 지체 없이 삭제하는 것을 원칙으로 합니다. 분쟁 대응 등 법령상 보존이 필요한 경우 해당 기간 보관합니다.
접속·보안 기록접속 IP 주소 등 서비스 제공업체가 보안·운영을 위해 자동 처리하는 정보서비스 제공, 장애 대응, 비정상 접근 방지각 서비스 제공업체의 설정 및 보유 정책에 따릅니다. 실제 설정을 확인해 이 방침에 구체적으로 공개합니다.

기사나 프로필에 제3자의 개인정보가 포함되는 경우에는 공개에 필요한 동의나 법적 근거를 확인해야 합니다. 사진은 업로드 과정에서 크기를 줄이고 메타데이터를 제거하도록 구성돼 있습니다.

3. 개인정보의 처리 근거

계정과 원고 관리는 기자실 이용 및 편집 업무 수행에 필요한 범위에서 처리합니다. 공개 기자 프로필·사진은 공개 여부를 확인한 뒤 반영하며, 법령상 의무나 서비스 보안에 필요한 처리는 해당 법적 근거와 필요한 범위에 따라 처리합니다.

4. 개인정보의 공개와 제3자 제공

새벽누리는 이용자의 개인정보를 외부에 임의로 제공하지 않습니다. 다만 이용자가 공개에 동의해 발행한 기사와 기자 프로필은 새벽누리 홈페이지에서 누구나 볼 수 있습니다. 공개된 이름·사진·기사 내용은 검색엔진, 인터넷 아카이브, 제3자의 복사본이나 GitHub 저장소의 과거 기록에 남을 수 있어, 홈페이지에서 삭제한 뒤에도 모든 사본을 즉시 없애기 어려울 수 있습니다.

5. 개인정보 처리 업무와 외부 서비스

서비스 제공업체이용 목적처리 정보

외부 서비스의 처리 지역·보유 기간은 실제 계정 설정과 서비스 계약을 확인해 공개해야 합니다. 공개 사이트 방문 기록은 GitHub Pages의 보안 운영 과정에서 IP 주소가 기록될 수 있습니다.

6. 국외 이전

새벽누리는 Cloudflare와 GitHub의 해외 인프라를 이용하고 있어 개인정보 또는 공개 콘텐츠가 국외에서 처리·보관될 수 있습니다. Cloudflare D1의 실제 데이터베이스 지역, 이전 국가·항목·시점·보유 기간과 적용 근거는 관리자 대시보드와 서비스 계약을 확인한 뒤 구체적으로 기재해야 합니다.

7. 개인정보의 파기

보유 기간이 끝나거나 처리 목적이 달성되어 개인정보가 더 이상 필요하지 않으면 지체 없이 파기합니다. 전자 파일은 복구할 수 없도록 삭제하고, 출력물이 있는 경우 분쇄 또는 소각합니다. 다만 공개된 기사·프로필의 복사본이나 저장소의 과거 기록은 새벽누리가 직접 통제할 수 없는 곳에 남을 수 있습니다.

8. 이용자와 법정대리인의 권리

이용자는 자신의 개인정보 열람·정정·삭제·처리정지를 요청할 수 있습니다. 기자 계정 정보와 원고는 기자실에서 제공되는 기능을 이용하거나 아래 담당자에게 요청해 주세요. 법정대리인은 법령에 따라 미성년자의 권리를 대신 행사할 수 있습니다. 요청을 받은 뒤 본인 확인 등 필요한 절차를 거쳐 처리합니다.

만 14세 미만 아동의 개인정보를 처리하는 경우에는 법정대리인의 동의를 확인하고 법령상 절차에 따라 처리해야 합니다.

9. 쿠키와 자동 수집 장치

기자실은 로그인 상태를 유지하기 위해 __Host-dawnuri_session 쿠키를 사용합니다. 이 쿠키는 보안 속성(HttpOnly·Secure·SameSite)을 적용하고, 로그인 세션을 식별하는 용도로만 사용합니다. 쿠키를 차단하면 기자실 로그인이 작동하지 않을 수 있습니다. 공개 뉴스 홈페이지의 쿠키·분석 도구 사용 여부는 배포 설정을 확인해 별도로 반영해야 합니다.

10. 개인정보의 안전성 확보 조치

  • 비밀번호 원문을 저장하지 않고, salt를 적용한 PBKDF2 해시값으로 저장
  • 계정별 권한을 제한하고, 로그인 세션에 만료 시간을 설정
  • HTTPS와 보안 쿠키 속성을 사용
  • 사진 업로드 시 크기를 줄이고 메타데이터를 제거
