# 공개 기자 프로필 등록 안내

Pages CMS의 **공개 기자 소개**에서 새 기자 프로필을 등록하세요. JSON 파일을 직접 수정할 필요는 없습니다.

저장소가 Public인 동안 이 폴더의 파일은 `visible: false`여도 GitHub에서 읽을 수 있습니다. 실명·학교·얼굴 사진·개인 연락처 등은 해당 기자의 공개 동의를 확인한 뒤 필요한 범위로만 입력하세요.

로그인용 ID, 비밀번호, 임시비밀번호, 승인 현황, API 토큰은 절대 이 폴더나 사이트 저장소에 넣지 마세요.

개별 기사의 `reporter_slug`에 프로필의 `slug`를 적으면 기사 바이라인이 기자 소개 페이지로 연결됩니다. 기사에 기자명이 없거나 프로필이 비공개면 기존 기자명만 표시합니다.
