# 새벽누리 v16 — 하단 메뉴 가로 정렬 수정

**v15의 기사 작성, 8개 분야, 사진 설명, 기자 소개, 공식 로고, 로그인 링크 설정 등은 모두 유지**합니다.
수정된 파일은 `public/assets/style.css` 한 개뿐입니다.

- 데스크톱: `새벽누리` 링크 4개를 **2열 × 2행**, `기사 분야` 8개를 **3열 × 3행**으로 정렬
- 태블릿: 목록을 세로로 배치하되 항목은 가로 그리드 유지
- 휴대전화: 너무 좁아지지 않도록 기사 분야를 **2열**로 줄바꿈

## GitHub 바로 적용하기
1. ZIP 파일을 다운로드하고 압축을 풀어 주세요.
2. `dawnuri-news` 저장소에서 **Code → Add file → Upload files**를 누르세요.
3. 압축 푼 폴더 **안의 `public` 폴더만** 끌어다 놓으세요.
4. 경로가 `public/assets/style.css`인지 확인한 다음 **Commit changes**를 누르세요.
5. **Actions → Deploy Dawnuri News** 완료 후 브라우저를 새로고침하세요.

**중요:** 이 ZIP에는 `content/`나 `.pages.yml`, `build.mjs`가 들어 있지 않습니다. 이미 발행한 기사와 프로필 정보는 그대로 남습니다.
